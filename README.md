# Sistema de Gestión para Restaurante (RestauranteApp)

## 📌 Descripción del Proyecto
Sistema web desarrollado en **Django** bajo una arquitectura modular, diseñado para la gestión integral de un restaurante. Permite administrar de forma eficiente las categorías, los platos del menú, las mesas, los meseros y el control de pedidos, optimizando la operación en áreas clave como el salón, la cocina y la caja.
